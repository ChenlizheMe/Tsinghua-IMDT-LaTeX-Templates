# 清华大学 IMDT 硕士开题报告 LaTeX 模板

清华大学深圳国际研究生院电子信息（互动媒体设计与技术，IMDT）开题材料的两份独立 LaTeX 模板。依据用户提供的 Word 文件转制，供填写和排版使用，并非学校官方发布的 LaTeX 模板。

| 文件 | 对应材料 | 版式 |
| --- | --- | --- |
| `main.tex` | 互动媒体设计与技术项目开题报告 | A4，封面、自动目录、四章正文、参考文献 |
| `work-plan.tex` | 硕士生（专业学位）选题报告及论文工作计划表（202401版） | B5（182 × 257 mm），四页，含评语、签名、成绩和实验安全栏目 |

两个文件均可独立编译，无需额外的 `.cls`、`.sty`、`.bib`、字体或图片文件。默认文献、图和公式均为明确标注的占位示例，正式提交前请替换或删除。

## 在 Overleaf 使用

1. 下载本仓库 ZIP，在 Overleaf 选择 **New Project → Upload Project** 并上传；也可在空项目中上传这两个 `.tex` 文件。
2. 在项目设置中把 **Compiler** 设为 **XeLaTeX**。使用近期的 TeX Live 环境即可；不要选择 pdfLaTeX。
3. 将 **Main document** 设为 `main.tex`，编译开题报告。
4. 将 **Main document** 改为 `work-plan.tex`，编译选题及论文工作计划表。
5. 每次分别下载对应 PDF。两个文件不是主文件与被引用文件的关系，不要用 `\input` 把它们合并。

## 连接 GitHub

如 Overleaf 账号具有 GitHub 同步权限，先在账号设置中关联 GitHub，再通过 **New Project → Import from GitHub** 导入本仓库。后续通过项目中的 **Integrations → GitHub** 手动推送或拉取变更；连接后不会自动实时同步。

Overleaf 官方将 GitHub 同步列为 Premium 功能，部分学校或团体订阅也包含此权限。没有该权限时，上传 ZIP 仍可编辑和编译，但不提供 GitHub 同步。详情见 [Overleaf GitHub synchronization 官方说明](https://docs.overleaf.com/integrations-and-add-ons/git-integration-and-github-synchronization/github-synchronization)。

## 填写开题报告

- 在 `main.tex` 开头的“个人信息填写区”修改题目、姓名、学号、培养单位、专业、导师和日期。题目按原模板要求控制在 25 个汉字（符）以内；导师填写学籍系统中的导师。
- 正式正文应写在 `\hint{...}` 命令之外。将整条提示命令替换为正文，不要直接把正式内容写进 `\hint` 内部。完成后把 `\ShowHintstrue` 改为 `\ShowHintsfalse` 隐藏剩余提示。
- 用 `\chapter`、`\section`、`\subsection` 写章、一级节、二级节标题；编号与目录自动生成，目录列至类似 `2.2.5` 的二级节标题。
- 原模板要求查阅不少于 20 篇中外文献、书面报告不少于 5000 字。本仓库是待填写模板，示例篇幅和参考文献数量不代表已经达到提交要求。
- 用 `\cite{文献键}` 引用，文末用 `\bibitem{文献键}` 添加真实条目，并按正文首次引用顺序排列。此版本使用内置文献环境，著录格式需按实际适用的写作指南人工核对，不会自动生成或检查 GB/T 7714 条目。
- 默认按原 Word 的四章范例组织内容，覆盖背景意义、文献综述、研究方案、创新点、难点、工作条件、阶段进展、预期成果、进度和答辩时间。可根据课题调整大纲。
- 图题在图下，表题在表上；图、表、公式按章编号。默认带三线表、图片占位和公式示例。

## 填写工作计划表

- 修改 `work-plan.tex` 开头的个人信息与内容宏。两个文件独立，因此共同信息需分别填写。
- 将对应选项宏中的 `{}` 改成 `{\tick}` 即可勾选，例如 `\newcommand{\TypeProduct}{\tick}`。每组“是／否”只选一项；论文类型只选一项。
- `\KeyReferences`、`\ResearchConditions`、`\ProjectCategory` 和 `\MainWorkPlan` 可填写多行文字，段落用 `\par` 分隔。
- 原件中的红色提示“须有导师评语、导师手写签名及日期”“不填”“导师填写”已保留。考核组意见栏按原模板提示留空，签名与成绩栏交相应人员填写。正式打印时可设置 `\ShowFormHintsfalse` 隐藏红色提示。
- 保留原件四页结构、三条脚注及 B5 纸张。打印时选择对应纸张和实际尺寸；若院系另要求 A4，请先修改 `geometry`，再检查分页。
- 表格单元格的高度为最小预留高度，内容增加时会增高；整页表格不自动跨页。填写超长内容时应另附续页并检查布局。

## 字体与格式依据

原件为以下两份材料：

1. 《硕士生（专业学位）选题报告及论文工作计划表（202401版）》；
2. 《互动媒体设计与技术项目开题报告模板 格式请参考最新版学位论文写作指南》。

开题报告采用原 Word 前部的详细规定：正文 12 bp、20 bp 行距，章标题三号黑体、一级节标题 14 bp、二级节标题 13 bp。原件后部范例还出现了“1.5 倍行距”等不同表述，本模板统一采用前部详细规定。A4 页边距依据所提供 Word 的页面参数；页眉采用当前章名、页码居中，正文从 1 开始编号。工作计划表保留原件 B5 纸张与表格结构，对表格宽度和分页做了适合 LaTeX 的调整。

默认中文使用 TeX Live 自带的 Fandol 宋体、黑体，西文使用 TeX Gyre Termes 和 Heros，以便直接在 Overleaf 编译。它们不是 Windows 的中易宋体、黑体、Times New Roman、Arial 的完全相同字库。若院系指定具体字库，导言区留有替换位置，可在有权使用这些字体的前提下自行配置。

原 Word 明确要求页面设置、篇眉、页码和参考文献以最新版学位论文写作指南为准。学校公开可查的 [2025 年 3 月研究生学位论文写作指南](https://www.dhs.tsinghua.edu.cn/wp-content/uploads/2023/12/2025032107444819.pdf) 可供对照；本仓库不声称已核实其为当前最新版本。正式提交时，以当期校内 info 写作指南和 IMDT 项目要求核对最终格式。

## 本地编译

安装包含中文支持的 TeX Live 或 MiKTeX 后，可分别运行：

```sh
latexmk -xelatex main.tex
latexmk -xelatex work-plan.tex
```

仓库中的 `.latexmkrc` 默认使用 XeLaTeX。本模板已使用基于 XeTeX 的编译器实际编译，并检查生成页面；Overleaf 的账号连接与导入需在使用者自己的账号中完成。
