# 原始 Word 与 LaTeX PDF 核对

核对日期：2026-10-21。以两份原始 Word 经 Microsoft Word 导出的 PDF 为版式参照，结合原文件的段落、字体、页面和表格属性核对。原 Word 字节及 SHA-256 保留在 references/originals/。

## 结论

工作计划表保留原件四页 B5 结构、全部字段、六条要求、三条脚注、签名栏和论文类型选项。去除论文题目占位提示，统一 Unicode 字符形式，并忽略空格、标点后，1109 个文字及数字字符与原件一致。这是内容核对结果，不是像素相似度。

开题报告是依据原件要求制作的写作模板，不是原 Word 十二页说明材料的逐页复印版。正文采用原件第 11 页的四章范例，封面、目录、正文顺序不变；说明页、空白页和互为替代的其他范例不加入正式报告。默认生成七页，填写内容后页数自然改变。

## 已修正的版式差异

| 项目 | 本轮修正 |
| --- | --- |
| 报告封面 | 标题由 18 bp 改为原件的 26 bp；个人信息由 14 bp 改为 16 bp；按原件基线恢复封面位置与填写提示 |
| 计划表封面 | 恢复校名和学位文字的疏排、标题留白、字段行距与日期间隔 |
| 评语及签字区域 | 重新校准导师评语、考核组意见、成绩栏的高度，避免占用原件预留的签字空间 |
| 论文类型 | 采用贯穿整表的四列网格，恢复独立勾选列及原件列宽比例 |
| 脚注及符号 | 将脚注标号放回原位置；脚注为 9 bp；勾选提示采用原件的根号式 √，而非 ✓ |
| 字体 | 私有工程使用真实宋体、黑体、Times New Roman、Arial；计划表第四页标题为加粗宋体，末尾脚注为楷体 |

原件计划表 PDF 的纸张约为 182.03 × 257.05 mm（Word 导出取整），模板使用标称 182 × 257 mm。按真实字库编译后，第二至第四页主要整宽横线的纵向位置与原件的差异控制在约 0.4 mm 内。字形渲染、标点挤压和表格线绘制仍会有 Word 与 XeLaTeX 的细微差别，不能据此宣称像素级一致。

## 报告中保留的有意调整

- 原 Word 实际页边距是左右 31.75 mm、上下 25.4 mm；原文同时要求页面设置按最新指南。本工程按已核对的学位论文指南采用四边 30 mm，并由 ThuThesis 管理标题、页眉和页码。
- 原件同时包含六章大纲及四章、六章两个参考范例。工程选择四章范例，将难点、条件、阶段性进展、外协和经费放在第三章，日程与答辩时间放在第四章。
- 原件的示意图和示例表用于讲解格式，工程以可编辑图表和真实 BibTeX 示例替换；不能把这些占位示例作为课题成果提交。
- 原件某处写 1.5 倍行距，其他段落和学校指南写固定 20 磅。按用户要求优先遵循指南，正文使用固定 20 bp。

## Overleaf 的编译问题

两份入口在 Overleaf 共用任务名 output。报告的旧根辅助文件引用了 perpage 计数命令，直接用于计划表会产生 pp@pagectr 未定义错误。latexmkrc 现在识别当前入口并在切换时只重建共享根辅助文件。本地独立任务名不受影响；GitHub Actions 额外测试报告—计划表—报告的共享任务名切换。

## 字体使用范围

公共仓库只包含字体配置与说明，不包含商业字体文件。私有 Overleaf 工程提供真实字库后自动启用严格字体模式；公共 ZIP 未附字库时仍是便携字体预览。核对实际字体应检查编译后 PDF 的字体资源，不能仅凭排版外观或源码中的字体名称判断。
