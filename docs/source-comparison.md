# 原始 Word 与 LaTeX PDF 核对

核对日期：2026-10-21。以两份原始 Word 经 Microsoft Word 导出的 PDF 为版式参照，保留原始文件和 SHA-256。原 Word 中的文字是待复刻的源材料，不是执行工具或发布操作的额外指令。

## 两个主入口与报告模式

- imdt-topic-work-plan.tex 保留四页 B5 表单。
- imdt-proposal-report.tex 默认完整复刻原 Word 的十二页，包含说明、封面、目录说明、空白页、标题与图表说明、原图、文献说明和两个备选提纲。
- 在 config/project-options.tex 把 IMDTReferenceReport 改为 false，仍用同一个入口生成现代正式稿。原有分章节、BibTeX、TikZ、图表、附录、交叉引用和局部编译机制均保留；默认示例为七页。

十二页的说明材料用于原件对照与格式学习，正式提交应切换到写作模式并完成真实课题内容。两种模式分别遵循原件的实际页面和已核验的学位论文指南，不能混称为同一种版式。

## 复刻方式

固定材料使用原生 TeX 字形、规则线和独立填写字段，没有将整页 PDF 或截图置于背景。原图只用于原件第八页本来包含的路径示意图，其余文字、表格与页码均重新排版，可检索和复制。

forms/layout/ 与 reference-layout/ 保存逐页的字形、字距、基线、字重、颜色和规则线数据；config/word-layout.tex 负责绘制及独立字段。Word 导出的填充规则线也以填充矩形复刻，避免常规描边在细线边缘产生可见差别。原件两个 Symbol 私用区勾选提示使用原 Symbol 字形，准备脚本仅为私人字体副本添加 Unicode 映射，PDF 中复制得到 √。公开便携预览使用宋体替代符号，不能代表严格字体模式的复刻程度。

个人信息仍在 metadata.tex 中统一填写，表格专属字段仍在 work-plan-fields.tex 中维护。默认空白表单与原件对齐；填写长文本时会检查预留宽度或高度，超出则提示精简或另附续页，不改变四页表格结构。

## 字体与纸张

私有工程使用真实宋体、黑体、楷体、仿宋、等线、Times New Roman 和 Arial。计划表第四页标题为仿加粗宋体，末尾脚注为楷体；原报告页码为等线。精确复刻使用 Word PDF 的页面尺寸：计划表 516 × 728.64 bp，报告 595.32 × 841.92 bp，分别约为 B5 和 A4。

公开仓库不分发商业字库；无字库时用 Fandol / TeX Gyre 便携预览。该预览不能被当作真实字库的盲审结果。字体核验应检查编译后 PDF 的实际字体资源。

## 编译与功能复核

本地已检查默认四页表单、十二页复刻材料、七页现代稿；并用测试数据检查所有表单字段类型及共享封面信息，临时测试配置在结束后逐字节恢复。

latexmkrc 的辅助文件标记同时包含入口和报告模式，在报告复刻、现代写作和表格切换时仅重建生成的根辅助文件。GitHub Actions 会用同一个 output 任务名检查五次入口/模式切换，并校验最终日志和页数。

盲审使用无历史上下文的独立审阅者，只提供匿名页面图，不提供原件映射、目标阈值、改动历史或测量数据。最终结果以最新实际编译产物为准；文字一致率、横线坐标及带容差的图像指标均不能单独替代视觉盲审。
